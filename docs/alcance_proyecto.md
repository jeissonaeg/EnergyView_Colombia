# Alcance del proyecto EnergyView Colombia

## Nombre del proyecto

EnergyView Colombia

## Objetivo general

Desarrollar un sistema de analítica de datos para procesar, visualizar, predecir y generar recomendaciones sobre la generación eléctrica en Colombia usando bases históricas de generación en kWh entre 2019 y 2026.

## Componentes del proyecto

1. Consolidación y limpieza de datos.
2. Generación de indicadores para dashboard.
3. Modelo de predicción mensual de generación.
4. Clasificación de comportamiento bajo, normal o alto.
5. Agente analítico de recomendaciones automáticas.
6. Dashboard final en Power BI.

## Herramientas

- Python para procesamiento y modelo.
- Power BI para visualización.
- Excel y CSV como formatos de salida.

## Modelo predictivo

El modelo principal será de regresión y buscará predecir la generación mensual en GWh.

## Agente de IA

El agente será un agente analítico basado en reglas inteligentes, indicadores históricos y resultados del modelo predictivo.
