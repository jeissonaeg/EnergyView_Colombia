# Datos del proyecto

Los archivos de datos crudos se guardan localmente en `inputs/raw/`.

Por ahora estos archivos no se suben a GitHub para mantener el repositorio liviano y evitar publicar datos por accidente. Para reproducir el proyecto, coloca aqui los archivos Excel de generacion de energia antes de ejecutar los scripts.

Estructura esperada:

```text
inputs/
  raw/
    Generacion_(kWh)_2019.xlsx
    Generacion_(kWh)_2020.xlsx
    ...
  processed/
```
