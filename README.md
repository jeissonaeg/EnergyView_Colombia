# EnergyView Colombia

Sistema inteligente de analítica para monitorear, predecir y generar recomendaciones sobre la generación eléctrica en Colombia entre 2019 y 2026.

## Objetivo del proyecto

Desarrollar una solución de analítica de datos que permita procesar bases históricas de generación eléctrica en kWh, construir indicadores para dashboard, entrenar un modelo de predicción mensual y generar recomendaciones automáticas mediante un agente analítico.

## Herramientas

- Python
- Pandas
- OpenPyXL
- Scikit-learn
- Power BI
- Excel / CSV

## Estructura del proyecto

- `inputs/raw/`: archivos originales de generación kWh.
- `outputs/data_limpia/`: bases limpias consolidadas.
- `outputs/dashboard/`: tablas para Power BI.
- `outputs/modelo/`: predicciones y métricas del modelo.
- `outputs/reportes/`: recomendaciones y reportes finales.
- `src/`: scripts de Python.
- `docs/`: documentación del proyecto.
